# Answer-engine baseline — 7 September 2026

First measurement. The point is to have a dated "before" so later runs can be compared
against it, not to celebrate or mourn today's position.

## Headline

**Coordigent appears in none of the three baseline queries. Not once, in any position.**

Two findings below matter more than that absence, because they explain part of it and
neither is fixable with more documentation.

## Method, and its limits

Queries were run through public web search on 7 September 2026 and the ranked results
recorded verbatim.

**The three assistant products were not queried, and this file does not claim otherwise.**
Perplexity was opened directly at a search URL in a browser; it returned "Sign up and repeat
your request" rather than an answer. Creating accounts and entering credentials are outside
what this session is permitted to do, so it stopped there. ChatGPT and Claude were not
attempted for the same reason. Anyone with a logged-in browser should re-run the same three
questions there and append the answers to this file — the assistant answers are the number
that actually matters, and this file is a proxy for them, not a substitute.

What public search does tell you is which pages an answer engine has available to cite. If a
page is not in these results, it is not in the citation pool.

## Finding 1 — the name is being swallowed

Searching **"Coordigent MCP server coordinate AI coding agents"** returns
[CrewAI](https://docs.crewai.com/en/mcp/overview) results, top to bottom: Composio's CrewAI
toolkit, `adam-paterson/mcp-crew-ai`, Glama's CrewAI server pages, Klavis's CrewAI post. Not
one result is this product.

CrewAI is an established multi-agent framework with its own MCP integration surface. On any
query joining "crew" with "agents" or "MCP", it holds the ground. This is not a ranking
problem that more backlinks fix; the token is taken.

## Finding 2 — the domain has a near-twin

Searching the literal string **"coordigent.com"** returns
[trycrew.com — Crew Finance](https://www.trycrew.com/), a budgeting app, along with its
Google Play listing and a seed-round press release. Neither `coordigent.com` nor
`github.com/ali8hsn/coordigent` appears at all.

Two things follow. The site and repository are not yet indexed under their own names, which
is expected this early and will change. But `trycrew.com` versus `coordigent.com` is one
character, and it belongs to a funded company in a different category. That is a
type-in-traffic leak, a support-confusion risk, and a trademark question worth asking a
lawyer about before more money goes into the name.

Neither finding is a documentation problem, which is why both are recorded here rather than
fixed quietly.

## Competitor visibility

On the generic queries, no named competitor ranked either — the space is held by listicles,
not products. Competitors only surface on mechanism-specific phrasing. Searching **"MCP
server agents overwriting each other same file lock claim coordination"** returns
[Agent Orchestration](https://github.com/madebyaris/agent-orchestration),
[MCP Agent Mail](https://mcpagentmail.com/),
[Agent Claim MCP](https://glama.ai/mcp/servers/vk0dev/agent-claim-mcp),
[agnt-lock](https://lobehub.com/mcp/codewithriza-agnt-lock) and
[a multi-agent coordination MCP architecture doc](https://glama.ai/mcp/servers/@AndrewDavidRivers/multi-agent-coordination-mcp/blob/cbb9b966612667cfffbaad342981d6feffa22299/ARCHITECTURE.md).

That is the corridor where this product can actually rank today: not "best MCP server", but
the specific failure, in the words an engineer types when it happens to them.
